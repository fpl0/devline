# Third-party notices

Documentation packs include source attribution and applicable notices under `data/docs/`. The app includes the same material under `Contents/Resources/catalog/docs/`.

The Java SE reference was generated from OpenJDK sources shipped with BellSoft Liberica JDK 26.0.2.1. The exact source subset, license, and generation inputs are distributed with that pack. [Java source archive](data/docs/java/26.0.2.1+devline.2/openjdk-26.0.2.1-javadoc-sources.zip) · [Documentation ingestion script](scripts/fetch-docs.py)

Local Infrastructure includes official offline references for ten services. The pack records each documentation publisher, source revision, license, coverage, and omissions, and includes the original notices. The RabbitMQ .NET tutorials use the publisher’s samples under Apache 2.0. Devline fetches service images from their publishers’ registries when prepared and records each image’s identity and license separately. [Infrastructure source notices](data/docs/infrastructure/2026.11.07+devline.4/SOURCES.md) · [Image provenance](data/infrastructure.json)

Starter bundles include their pinned third-party dependencies. Go and Rust retain vendored notices. Python wheels, Ruby gems, NuGet packages, Maven artifacts, Hex sources, and npm packages retain upstream license information. Package versions and provenance are recorded in their respective manifests and lockfiles. [Maven upstream artifact and source index](third-party/MAVEN.md) · [npm upstream notices and native package sources](third-party/NPM.md)

Optional service client packs contain original publisher and community package artifacts for nine runtimes. Each [recommendation catalog](data/service-clients/) identifies its maintainer source and support category; recommending a client does not make it an official service SDK. The [artifact directories](data/service-clients/artifacts/) retain native package metadata, lockfiles, and upstream notices. Their `inventory.json` files record the exact paths, sizes, and SHA-256 digests of the distributed artifacts.

Swift client packs preserve the pinned Git source snapshots, including original license files and bundled dependency notices. Readable copies of the 40 repositories’ primary licenses accompany the cache. [Swift package revisions](data/service-clients/artifacts/swift/Package.resolved) · [Swift licenses](data/service-clients/artifacts/swift/licenses/)

The Java client pack also includes the exact upstream source archives for all 182 distributed Maven JARs. Its source index records each binary, source download URL, and source archive checksum. MySQL Connector/J 9.7.0 is distributed under GPLv2 with Oracle’s additional permissions and Universal FOSS Exception; its complete tagged source tree, including build files, accompanies the source JAR. Jakarta Mail 2.0.5 retains the Eclipse Public License 2.0 and applicable secondary-license notices. These component licenses remain distinct from Devline’s license. [Java source index](data/service-clients/artifacts/java/SOURCES.json) · [Bundled source archives](data/service-clients/artifacts/java/sources/) · [MySQL and Jakarta Mail license notices](data/service-clients/artifacts/java/licenses/)

The Playwright starter includes Microsoft's Apple Silicon WebKit 27.2 build 2388 for Playwright 1.65.0. The browser archive preserves the upstream executable and frameworks. Exact source instructions, the corresponding Playwright patch, and the WebKit, ANGLE, WebRTC, and other upstream license notices ship alongside it. [Browser provenance](data/templates/node/playwright-automation/1.0.0/project/BROWSER.json) · [Browser sources and notices](data/templates/node/playwright-automation/1.0.0/project/browser-archive/SOURCES.md) · [WebKit licensing](https://webkit.org/licensing-webkit/)

The Devline core uses Rust crates listed in `core/Cargo.lock`. [Rust dependency notices](third-party/CARGO.md)

The macOS app embeds [Sparkle 2.10.1](https://github.com/sparkle-project/Sparkle/releases/tag/2.10.1) for authenticated app updates. [Sparkle and bundled component licenses](third-party/sparkle/LICENSE)

The macOS documentation reader bundles [Highlight.js 11.12.0](https://github.com/highlightjs/highlight.js/releases/tag/v11.12.0) under the BSD 3-Clause License. Its local script concatenates `highlight.min.js` with the `dockerfile`, `elixir`, `erlang`, `groovy`, `http`, `pgsql`, `powershell`, `properties`, and `protobuf` browser grammars from the same published package. [Upstream package](https://registry.npmjs.org/@highlightjs/cdn-assets/-/cdn-assets-11.12.0.tgz) · [Highlight.js license](third-party/highlight.js/LICENSE)

The Tauri documentation snapshot retains MIT and Apache-2.0 notices from its pinned sources. **The Swift Programming Language** snapshot retains Apache 2.0 with the Swift Runtime Library Exception and Swift.org attribution. [Tauri sources](data/docs/tauri/2.12.5+devline.1/SOURCES.md) · [Swift sources](data/docs/swift/6.4.0+devline.1/SOURCES.md)

SwiftUI imports use Apple’s original declarations, documentation comments, and available examples from the selected local macOS SDK. The local `SOURCES.md` records the SDK build, compiler, modules, and extraction method. Devline stores these snapshots on the Mac that generated them and excludes them from releases and portable exports. [Documentation policy](DOCUMENTATION-POLICY.md) · [Apple Xcode and SDK agreement](https://www.apple.com/legal/sla/docs/xcode.pdf)
