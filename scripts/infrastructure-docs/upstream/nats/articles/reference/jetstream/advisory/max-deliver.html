Max Deliveries Exceeded

Message exceeded max delivery attempts.

Subscription Subject

$JS.EVENT.ADVISORY.CONSUMER.MAX_DELIVERIES.{stream}.{consumer}

Where:

  • {stream} is the stream name
  • {consumer} is the consumer name

Event Schema
