Get Next Message

Gets next message(s) from a consumer.

Subject

$JS.API.CONSUMER.MSG.NEXT.{stream}.{consumer}

Where {stream} is the stream name and {consumer} is the consumer name.

Request

A request to the JetStream $JS.API.CONSUMER.MSG.NEXT API
