Delete Stream

Deletes an existing stream.

Subject

$JS.API.STREAM.DELETE.{stream}

Where {stream} is the name of the stream to delete.

Response

A response from the JetStream $JS.API.STREAM.DELETE API

One of the following:
Option 1 (object)
errorobjectrequired
Option 2 (object)
successbooleanrequired
