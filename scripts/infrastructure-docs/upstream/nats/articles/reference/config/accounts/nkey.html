nkey

Hot Reloadable
Copied onto the live account by shallowCopy, but in config (non-operator) mode nothing reads Account.Nkey, so changing it has no observable effect at reload or at startup.

Public NKey that identifies this account (an A-prefixed public account key). The server rejects the config if the value is not a valid public account NKey.
