dial_timeout

Available since NATS Server 2.15
Requires Restart

How long to wait for the TCP connection to this remote to be established. Overrides the server-wide leafnodes.dial_timeout for this remote only. If not set, the server-wide value applies, which itself defaults to 1s.

Types

TypeDescriptionChoices
durationDuration as a string with units such as 100ms, 10s, 5m, or 2h.-
