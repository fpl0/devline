gateway

Hot Reloadable
Only TLS certificate material reloads, for this gateway and its remotes, and only for connections established afterwards. Every other gateway setting fails the reload — host, port, name, authorization, the remote list, and the TLS timeout, verify_and_map, verify_cert_and_check_known_urls and pinned_certs.

Configuration for setting up gateway connections between clusters.
