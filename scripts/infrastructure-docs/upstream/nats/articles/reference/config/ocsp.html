ocsp

Hot Reloadable

OCSP Stapling is honored by default for certificates that have the status_request Must-Staple flag. If explicitly disabled, the server will not request staples even if Must-Staple is present.

Types

TypeDescriptionChoices
booleantrue, false
objectAn object with a set of explicit properties that can be set.-
