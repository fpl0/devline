# FUNCTION KILL

Terminates a function during execution.

## Syntax

```text
FUNCTION KILL (null)
```


**Available since** 7.0.0

**Group** scripting

**Time complexity** O(1)

**Arity** 2

**ACL categories** SCRIPTING

**Command flags** NOSCRIPT, ALLOW_BUSY

## Reply schema

```json
{
  "const": "OK"
}
```
