# VISMEMBER

Check if an element exists in a vector set

## Syntax

```text
VISMEMBER key element
```


**Available since** 8.2.0

**Group** vector_set

**Time complexity** O(1)

**Arity** 3

**Command flags** READONLY

## Arguments

```json
[
  {
    "name": "key",
    "type": "key"
  },
  {
    "name": "element",
    "type": "string"
  }
]
```
