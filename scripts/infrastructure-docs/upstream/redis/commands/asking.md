# ASKING

Signals that a cluster client is following an -ASK redirect.

## Syntax

```text
ASKING (null)
```


**Available since** 3.0.0

**Group** cluster

**Time complexity** O(1)

**Arity** 1

**ACL categories** CONNECTION

**Command flags** FAST

## Reply schema

```json
{
  "const": "OK"
}
```
