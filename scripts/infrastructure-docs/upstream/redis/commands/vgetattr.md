# VGETATTR

Retrieve the JSON attributes of elements

## Syntax

```text
VGETATTR key element
```


**Available since** 8.0.0

**Group** vector_set

**Time complexity** O(1)

**Arity** 3

**Command flags** READONLY

## Arguments

```json
[
  {
    "name": "key",
    "type": "key"
  },
  {
    "name": "element",
    "type": "string"
  }
]
```
