# Connect with Redis clients

Here, you will learn how to connect your application to a Redis database. If you're new to Redis, you might first want to [install Redis with Redis Stack and RedisInsight](https://redis.io/docs/getting-started/install-stack/).

For more Redis topics, see [Using](https://redis.io/docs/manual/) and [Managing](https://redis.io/docs/management/) Redis.

If you're ready to get started, see the following guides for the official client libraries you can use with Redis. For a complete list of community-driven clients, see [Clients](https://redis.io/resources/clients/).


## High-level client libraries

The Redis OM client libraries let you use the document modeling, indexing, and querying capabilities of Redis Stack much like the way you'd use an [ORM](https://en.wikipedia.org/wiki/Object%E2%80%93relational_mapping). The following Redis OM libraries support Redis Stack:

* [Redis OM .NET](https://redis.io/docs/clients/om-clients/stack-dotnet/)
* [Redis OM Node](https://redis.io/docs/clients/om-clients/stack-node/)
* [Redis OM Python](https://redis.io/docs/clients/om-clients/stack-python/)
* [Redis OM Spring](https://redis.io/docs/clients/om-clients/stack-spring/)
