Khepri and Upgrades

Khepri is always enabled in RabbitMQ 4.3 and later. No additional configuration is required.

Upgrading a Mnesia-Based Cluster

Before upgrading a RabbitMQ 4.2 cluster, enable all stable feature flags, including khepri_db, and allow the metadata migration to complete. See the RabbitMQ 4.2 migration instructions and the upgrade guide.
