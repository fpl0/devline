(3) Long-Term Support (LTS) releases of the JDK are fully supported (currently JDK 8, 11, 17, 21, and 25). Intermediate releases (e.g. 27) are supported on a best-effort basis, meaning bug reports are accepted and addressed as far as technically possible but without any service level guarantees.
