# __PROJECT_NAME__

Count lines, words, and UTF-8 bytes in a text file and print a JSON report.
The starter uses Elixir 1.20 and Erlang/OTP 29 without Hex dependencies.

Run the example with `./devline.sh run`. To summarize another file, use
`./devline.sh exec elixir -S mix run summary.exs "path/to/file.txt"`.
Run `./test-offline.sh` to check the example and error handling.
